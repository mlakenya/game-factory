# Вынести шаблон из игры

Шаблоны появляются из игр, которые уже вышли, а не проектируются заранее.

## Когда
- Игра прошла модерацию, постмортем (`postmortem`) рекомендует «вынести в шаблон».
- Планируется ещё минимум одна игра на этой механике **с другим поворотом**.

## Шаги
1. Ветка `template/<жанр>`.
2. `cp -r games/<id> templates/<жанр>`, затем убрать всё специфичное: контент, ассеты, тексты → заглушки.
3. Всё, что будет различаться между играми, — в `game.config.ts` и `content/`. В `src/` не должно остаться
   констант конкретной игры.
4. Общий код, полезный любым жанрам, — в `engine/` (отдельным коммитом).
5. `README.md` шаблона: что настраивается в конфиге, какие точки расширения, ссылка на игру-источник.
6. `npm run check` — смоук подхватит шаблон автоматически. Добавить `tests/e2e/<жанр>.spec.ts` на главный сценарий.
7. Проверка: `npm run new-game -- tmp-check --template <жанр>` собирается и играется без правок; удалить `games/tmp-check`.
8. Обновить список шаблонов в скилле `new-game` и в `CLAUDE.md`.
