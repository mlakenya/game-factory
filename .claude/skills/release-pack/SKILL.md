# Пакет релиза

## Шаги
1. Прогон: `npm run check` зелёный, плейтест-отчёт без блокеров.
2. Чек-лист из скилла `yandex-moderation` — пройти пункты без `[auto]`.
3. Архив: `npm run pack -- <id>` → `release/<id>/<id>-YYYY-MM-DD.zip` (index.html в корне, сборка уже проверена audit).
   Для Playgama: `npm run pack -- <id> --target playgama` → `release/<id>/<id>-playgama-YYYY-MM-DD.zip`; требования и отличия — скилл `platform-sdk`.
   Для CrazyGames: `--target crazygames` → `release/<id>/<id>-crazygames-YYYY-MM-DD.zip`; обложки 3 формата и 2 превью-видео (см. `platform-sdk`).
4. Тексты в `games/<id>/release/texts.md` (RU и EN):
   - Название (до ~50 символов, без «лучшая», «топ», капса).
   - Короткое описание: что делает игрок, одной фразой.
   - Полное описание: механика, цель, особенности; без обещаний, которых нет в игре.
   - Как играть: управление на ПК и телефоне.
   - Теги/категории.
5. Медиа — скилл `promo-media`.
6. Запись в `knowledge/moderation-log.md` со статусом «отправлено» после того, как человек отправит.

## Правила
- Отправку на модерацию делает человек. Claude готовит всё и даёт ссылку/путь к архиву.
- Каждое обновление — новая запись в журнале с номером версии.
- Размер: цель < 20 МБ; если больше — сжать текстуры (webp), звук (ogg 96 kbps), убрать неиспользуемое.
