# Ассеты игры

Результат: `art/<id>/assets/` с готовыми файлами, `art/<id>/CREDITS.md`, витрина для человека и статус «ассеты одобрены».
После этого `npm run new-game` копирует ассеты в `games/<id>/assets/`. Без этого статуса игра не создаётся.

## Шаги
1. **Список ассетов** `art/<id>/ASSETS.md` из концепта: каждый предмет, персонаж, фон, элемент интерфейса, эффект;
   у каждого — размер на экране, состояния (обычный, подсвечен, заблокирован, разбит), откуда берём (генерация / пак).
   Список включает всё, что есть в концепте: каждую систему и каждый крючок удержания, а не только основную механику.
2. **Генерация** — строго по скиллу `image-gen` (задание, запуск на ноутбуке, забор, отбор, шаблоны промптов по типам ассетов).
   Состояния предмета — тот же seed и одно изменённое слово.
3. **Паки.** Интерфейс и иконки — из бесплатных паков (см. `art-style`), перекрасить в палитру.
4. **Сведение.** `unify.py cut <файлы> --out art/<id>/assets/<группа> --size <px> --palette art/<id>/STYLE.md --outline <как в STYLE>`.
   Размер в файле — 2× от размера на экране. Имена — латиница, по смыслу (`toys/ball-red.png`).
5. **CREDITS.md** (`art/<id>/CREDITS.md`): каждая группа или файл — источник и лицензия, например
   `` `toys/` — FLUX.2 klein 4B (Apache 2.0), сгенерировано в фабрике `` или `` `ui/` — Kenney UI Pack (CC0) ``.
   CC BY — с автором дословно. `npm run ideas -- --check` и `audit` проверяют, что ни один файл не пропущен.
6. **Витрина**: `unify.py sheet art/<id>/assets/* --out art/<id>/boards/assets-sheet.jpg --bg <фон игры>` и 2–3 макета экранов
   с настоящими ассетами. Отправить человеку вложениями. Переделать то, что выпадает из стиля.
7. **Решение человека** «ассеты одобряю» → `npm run ideas -- set N "ассеты одобрены"`, `--check`, коммит `art/<id>: assets approved`, PR.
   Затем скилл `new-game`.

## Правила
- Только бесплатные источники с коммерческой лицензией. Нет лицензии — нет файла в игре.
- Модель FLUX.2 klein 4B (Apache 2.0). Не klein 9B и не другие некоммерческие модели.
- Сырые генерации — в `art/<id>/raw/`, в git только отобранные (raw большие: добавить `art/*/raw/` в коммит только по просьбе).
- Новые картинки во время разработки идут тем же путём: генерация → `unify.py` → `CREDITS.md`. Рисовать спрайты кодом можно
  только для эффектов (частицы, вспышки), не для предметов и персонажей.
- Ассеты одобряет человек: статус ставится только по его словам в этом разговоре.
