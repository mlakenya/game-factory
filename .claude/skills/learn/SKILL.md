# Пополнение базы знаний

Фабрика становится лучше, только если выводы попадают в скиллы и проверки, а не остаются в чате.

## Куда писать
| Вывод | Куда |
|---|---|
| Отказ модерации | `knowledge/moderation-log.md` + пункт в `yandex-moderation` + проверка в `pipeline/audit.mjs` |
| Правило для всего репо | `CLAUDE.md` (держать ≤ 150 строк — иначе вынести в скилл) |
| Как делать конкретную задачу | соответствующий скилл, раздел «Шаги» или «Подводные камни» |
| Новая повторяемая задача | новый скилл по `knowledge/templates/SKILL.template.md` |
| Наблюдение о рынке | `knowledge/market/` (скилл `market-scan`) |
| Итоги игры | `knowledge/postmortems/<id>.md` |

## Правила
- Каждая запись с источником и датой: `(отказ 2026-12-01, merge-cats)`.
- Лучше автоматическая проверка, чем строка в чек-листе.
- Устаревшее удалять, а не копить. Скилл короче 200 строк; если длиннее — разбить.
- `description` скилла отвечает на «когда применять» — по ней Claude решает, загружать ли скилл.
