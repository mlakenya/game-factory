# Скан рынка

Цель — сигналы для выбора следующей игры, а не новости ради новостей. Каждая запись отвечает на вопрос:
**что из этого может сделать наша фабрика в ближайший месяц?**

## Ежедневный скан → `knowledge/market/daily/YYYY-MM-DD.md`
Время: 10–15 минут работы. Если файл за сегодня уже есть — дополнить, а не перезаписывать.

### Источники (по порядку, пропускать недоступные и отметить это в отчёте)
1. Каталог Яндекс Игр: https://yandex.ru/games/ — разделы «Новые», «Популярные», подборки на главной.
2. Каталог Playgama: https://playgama.com/ — новые, популярные/трендовые, подборки на главной и в категориях.
   Это наша вторая площадка (там уже живёт черновик «Наряди ёлку»), аудитория в основном англоязычная.
3. Каталог CrazyGames: https://www.crazygames.com/ — разделы New, Trending/Hot, Updated, топ по категориям.
   Самый крупный западный веб-портал: хорошо показывает, какие механики растут вне СНГ.
4. WebGameAnalytics: https://webgameanalytics.com/ — новинки, «прорывы», удаления, разработчики.
5. Новости площадок и разработчиков: App2Top, DTF, Хабр, vc.ru (поиск «Яндекс Игры» за последние сутки-двое),
   блоги и новости Playgama и CrazyGames (developer.crazygames.com, docs.playgama.com) — изменения правил, SDK, выплат.
6. Внешние тренды, откуда приходят темы: Roblox (топ игр), мобильные топы, детский YouTube/TikTok-мемы.
7. `knowledge/market/watchlist.md` — что изменилось у отслеживаемых игр и жанров.

Если страница каталога не грузится через WebFetch (часто это JS-витрина), ищи через WebSearch:
`site:playgama.com new games`, `site:crazygames.com trending`, «CrazyGames top games this week» и т. п.
Каталог, который так и не открылся, — в «Недоступные источники»; не заполнять его по памяти.

Сравнивай площадки между собой: игра или механика в топе Playgama/CrazyGames, которой нет (или мало) на Яндексе, —
кандидат в идею с локализацией под RU; растущее на всех трёх — сильный сигнал.

Используй WebSearch/WebFetch. Не выдумывай цифры: если число не нашлось — пиши «нет данных».
Каждый факт — со ссылкой.

### Формат файла
```markdown
# Скан рынка YYYY-MM-DD

## Главное за день (до 3 пунктов)
- <сигнал> — <почему важно для нас> ([источник](url))

## Новые и растущие игры
| Игра | Площадка (Яндекс / Playgama / CrazyGames / Roblox …) | Жанр | Сигнал (новинка / рост / в топе N дней) | Механика в одной фразе | Можем сделать? (да/нет/с поворотом) | Ссылка |

## Жанры и темы
- <жанр/тема>: растёт / стабильно / падает — <наблюдение>

## Площадки
Изменения правил, SDK, модерации, монетизации, события и сезонные подборки — подзаголовком на каждую площадку,
где что-то нашлось (Яндекс Игры, Playgama, CrazyGames). Пустые не писать.

## Идеи для концептов
- **N. <идея>** — поворот: <чем отличается от топа>; шаблон: <какой>; сигнал: <ссылка выше>; сложность: <дни, оценка>
- Усиливает идею M: <новый сигнал к уже известной идее> (если есть)

## Недоступные источники
- <источник>: <причина>
```

### Идеи → реестр `knowledge/ideas.md`
Скан заканчивается 2–4 идеями, из которых человек выберет, по каким писать концепт (скилл `concept`).
- Сначала прочитай реестр. Не предлагай заново идею, которая там уже есть (в любом статусе, включая «отклонена»):
  если появился новый сигнал к ней — строка «Усиливает идею M» в скане, а в реестре ничего не меняй.
- Каждой новой идее — следующий номер (`npm run ideas -- next`, дальше по порядку) и строка в реестре
  со статусом «идея», ссылкой на сегодняшний скан и пустым «Концептом».
- Название в реестре — одна строка: тема + поворот, чтобы выбрать, не открывая скан.
- Если сильных идей нет — так и написать; не добивать до 2 слабыми.
- Скан никогда не пишет концепты и не меняет статусы существующих идей: это решение человека.
- `npm run ideas -- --check` должен проходить перед коммитом.

### После записи
- Обнови `knowledge/market/watchlist.md`, если появилась игра или жанр, за которым стоит следить 1–2 недели.
- Если найдено изменение правил модерации или SDK — добавь пункт в скилл `yandex-moderation` с пометкой
  «(не проверено, из скана YYYY-MM-DD)».
  Изменения правил Playgama и CrazyGames туда не писать: только в раздел «Площадки» скана.

## Недельная сводка (по понедельникам) → `knowledge/market/weekly/YYYY-Www.md`
Собирается из daily-файлов за прошедшую неделю плюс свежий взгляд на каталог.

```markdown
# Рынок, неделя YYYY-Www

## Выводы недели (3–5 пунктов)
## Жанры: что растёт и что падает (таблица с динамикой, колонки по площадкам: Яндекс / Playgama / CrazyGames)
## Топ-5 игр недели, которые стоит разобрать (с площадкой)
## Разрывы между площадками: что растёт на Playgama/CrazyGames и ещё не занято на Яндексе
## Рекомендация: 2–3 концепта для фабрики
Для каждого: core loop, поворот, шаблон, сложность (дни), почему сейчас. Ссылки на сигналы.
## Что убрать из watchlist
```

## Правила
- Только факты со ссылками; оценки помечать «оценка».
- Не копировать чужие игры: в «Идеях» всегда свой поворот (рескины снимают с каталога).
- «Имитации, шутки, тесты» и игры с ИИ внутри — не рекомендовать (платформа их удаляет).
- Сезонность: ноябрь–декабрь — лучшие месяцы для релизов, новогодние темы начинать в ноябре.
