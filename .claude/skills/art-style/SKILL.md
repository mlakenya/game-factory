# Визуальный стиль

Между одобренным концептом и разработкой. Результат: `art/<id>/STYLE.md` (библия стиля), доски в `art/<id>/boards/`,
статус «стиль одобрен» в `knowledge/ideas.md`. Почему этап есть: CrazyGames отказал «Наряди ёлку» за общее качество,
а нарисованная кодом графика упирается в потолок ([ресерч](../../../knowledge/research/visual-style-2026-11-08.md)).

## Когда применять
- Идея в статусе «одобрен» (человек сказал «делаем» по концепту).
- Человек просит переделать стиль игры, у которой он ещё не утверждён.

Платные тарифы не использовать (решение человека 2026-11-08). Recraft бесплатный — только наброски, в игру нельзя (нет коммерческих прав).

## Шаги
1. **Референсы.** Из сканов (`knowledge/market/`) и концепта — 3–5 трендовых игр жанра. Для каждой одной строкой:
   палитра, обводка, объём, свет, как выглядит интерфейс.
2. **Три направления**, заметно разных (например «плоский вектор с толстой обводкой», «мягкий объём, пластилин»,
   «рисованная гуашь»). Для каждого: палитра 8–16 цветов `#rrggbb`, префикс стиля для промптов, пак интерфейса, шрифт.
3. **Генерация досок** — строго по скиллу `image-gen`: одно задание `boards-<дата>` на все три направления
   (6–10 ключевых предметов из концепта, фон, кнопка на каждое), 3–4 варианта на предмет, отбор по чек-листу оттуда.
4. **Сведение.** `python3 pipeline/art/unify.py cut … --palette art/<id>/STYLE-<x>.md --outline N` и `split` для листов.
5. **Доска стиля** на каждое направление (`art/<id>/boards/<x>.png`): макет главного игрового экрана из этих ассетов
   (собрать сценой Phaser или композицией картинок), ряд предметов, кнопка, надпись шрифтом. Плюс палитра полосой.
6. **Показ человеку.** Три доски одним сообщением (вложения), под каждой — одна строка «чем хорош, чем рискован». Рекомендация одна.
7. **Решение.** По словам человека («беру второй», «стиль одобряю», правки):
   - правки — переделать доску, статус не меняется;
   - выбор — `art/<id>/STYLE.md` по `knowledge/templates/STYLE.template.md`, лишние направления удалить из `boards/`
     (оставить выбранное), `npm run ideas -- set N "стиль одобрен"`, `npm run ideas -- --check`.
8. Коммит `art/<id>: style approved`, PR. Дальше скилл `assets`.

## Правила
- Один стиль на игру. Всё, что в игре видно, подчиняется `STYLE.md`: палитра, обводка, свет, шрифт.
- Модель только с коммерческой лицензией: FLUX.2 klein **4B** (Apache 2.0). klein 9B, FLUX.1 dev, Qwen-Image 2.1 — некоммерческие, не использовать.
- Статус «стиль одобрен» ставится только по словам человека в этом разговоре.
- Механики на этом этапе не меняются: они утверждены в концепте. Если стиль требует другой механики — спросить человека.
- Сеть: из облачной сессии закрыты kenney.nl, opengameart, itch.io, huggingface — скачивание только через ноутбук.
