# Новая игра

Результат: ветка `game/<id>`, папка `games/<id>/`, играбельный билд, который проходит `npm run check`.

## Шаги
1. **Одобрены концепт, стиль и ассеты.** В `knowledge/ideas.md` идея со статусом «ассеты одобрены» и концептом `<id>`,
   в `art/<id>/` есть `STYLE.md`, `assets/` и `CREDITS.md`. Если статус «одобрен» — сначала скилл `art-style`,
   если «стиль одобрен» — скилл `assets`. Одобряет только человек; `npm run new-game` сам откажется без статуса «ассеты одобрены».
2. **Ветка.** `git checkout -b game/<id>` от свежего `main`.
3. **Каркас.** `npm run new-game -- <id> --template <шаблон>` (сейчас есть только `blank`).
   Скрипт скопирует концепт в `CONCEPT.md`, стиль в `STYLE.md`, ассеты в `assets/` и `CREDITS.md`, переведёт идею в «в разработке».
   Закоммить это первым коммитом.
4. **Конфиг.** `game.config.ts`: id, название RU/EN, ориентация, цвета, параметры баланса.
5. **Core loop первым.** Замени механику в `GameScene` на свою. Логику, которую можно отделить от Phaser
   (правила, подсчёт очков, генерация уровней), — в `src/logic/` с юнит-тестами в `tests/unit/<id>.*.test.ts`.
6. **Тексты.** Все строки в `content/locales.ts`, RU и EN с одинаковыми ключами.
7. **Проверка.** `npm run dev -- <id>`, затем `npm run build -- <id> && npm run audit -- <id>`, затем
   `npm run test:e2e`. Смоук-тест подхватит игру сам; добавь `tests/e2e/<id>.spec.ts` для главного сценария.
8. **Плейтест.** Агент `playtester` (`.claude/agents/playtester.md`) играет и пишет отчёт.
9. **PR** в `main` с чек-листом из скилла `yandex-moderation` в описании.

## Правила
- Маленькими шагами: каждый коммит собирается и проходит тесты.
- Не меняй `engine/` в ветке игры без необходимости. Если нужно — отдельный коммит `engine: …` и `npm run check` для всех.
- Объём — как в концепте (планка насыщенности). Остальное в «Отложено» в CONCEPT.md.
- Свой поворот обязателен: если игра отличается от шаблона только картинкой — вернись к шагу 1.
- Крупное отклонение от концепта (другая механика, вдвое больше срок) — сначала спросить человека и записать
  решение в `CONCEPT.md`.
- После публикации — статус «выпущена» в реестре (`npm run ideas -- set N выпущена`).

## Ассеты
- Графика: только из `assets/` (утверждённые на этапе `assets`) в стиле `STYLE.md`. Новая картинка — через скилл `assets`
  (генерация → `pipeline/art/unify.py` → `CREDITS.md`). Кодом рисовать можно только эффекты (частицы, вспышки).
  `audit` не пропустит файл из `assets/` без строки в `CREDITS.md`.
- Звук: короткие файлы в `public/`, `ogg` + `mp3`. Всё должно глушиться через `AudioGate`.
