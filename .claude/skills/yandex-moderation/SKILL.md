# Модерация Яндекс Игр

Около 72% отказов — техника, SDK и интерфейс. Почти всё это ловится до отправки:
`npm run pack -- <id>` (build + audit) и `npm run test:e2e`. Этот скилл — то, что скрипты не ловят.

Источник правды: https://yandex.ru/dev/games/doc/ru/concepts/requirements — перед релизом сверить,
не изменились ли требования. Если изменились — обновить этот файл и `pipeline/audit.mjs`.

## Перед отправкой: чек-лист
Помечено `[auto]` — проверяет `pipeline/audit.mjs` или e2e. Остальное — руками или агентом `playtester`.

### SDK и жизненный цикл
- [auto] `<script src="/sdk.js">` в index.html, игра работает и без SDK (заглушка).
- [auto] `gameReady()` (LoadingAPI.ready) вызывается, когда игра реально готова, не раньше.
- [auto] `gameplayStart()/gameplayStop()` есть; руками: stop в меню, паузе, на экране результата, во время рекламы.
- Игра встаёт на паузу и глушит звук при `game_api_pause`, сворачивании вкладки и во время рекламы.
- Прогресс сохраняется через облачные сохранения (`SaveStore`), переживает перезагрузку.

### Реклама
- Межстраничная только в естественных паузах (между уровнями, после проигрыша, при возврате в меню). Не во время игры, не по таймеру посреди действия.
- Rewarded только по кнопке, которая честно говорит, что будет реклама и какая награда. Награда выдаётся только при `onRewarded`.
- Если реклама не загрузилась — игра продолжает работать без зависаний.

### Интерфейс
- [auto] Нет прокрутки страницы. Нет выделения текста, контекстного меню, зума двойным тапом (`lockPageGestures`).
- Всё помещается в экран на телефоне в портрете и на десктопе; кнопки не меньше ~44px на телефоне.
- Нет «кнопок-пустышек», неработающих ссылок, упоминаний других площадок, внешних ссылок.
- Есть понятный старт: игрок за 5 секунд понимает, что делать (обучение или подсказка).

### Локализация
- [auto] Русский обязателен, английский рядом с теми же ключами.
- Язык берётся из SDK автоматически, не по выбору в меню по умолчанию.
- Название, описание, скриншоты в консоли — на каждом заявленном языке.

### Контент и сборка
- [auto] Размер сборки ≤ 100 МБ (цель < 20 МБ), index.html в корне архива, пути относительные, нет внешних CDN.
- [auto] Нет обращений к ИИ-API в игре (правило 1.23).
- Нет консольных ошибок (e2e ловит), нет отладочных панелей и FPS-счётчиков.
- Игра не «имитация/шутка/тест» и не рескин уже опубликованной игры — такие снимают.
- Права на все ассеты, звуки и шрифты (записать источник в `games/<id>/CREDITS.md`).

## Когда пришёл отказ
1. Скопировать причину дословно в `knowledge/moderation-log.md`.
2. Исправить, прогнать `npm run check`.
3. Добавить пункт в чек-лист выше с пометкой `(отказ YYYY-MM-DD, <id>)`.
4. Если проверку можно автоматизировать — добавить её в `pipeline/audit.mjs` или e2e. Это главный способ, которым фабрика учится.
5. Повторная отправка — после каждого отказа ожидание растёт (до ~16 дней), поэтому не спешить с повтором без полного прогона.
