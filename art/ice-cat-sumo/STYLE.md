# Стиль: Котосумо на льдине

> Библия стиля. Утверждена человеком (скилл `art-style`), дальше ей подчиняются все ассеты и интерфейс.

**Игра:** ice-cat-sumo
**Дата утверждения:** 2026-11-12
**Направление:** плоский мультяшный стикер-вектор с толстой тёмно-синей обводкой, яркие плоские цвета, одна ступень тени.

## Палитра
Основные цвета (скрипт `pipeline/art/unify.py --palette` берёт цвета из этого раздела):
#1b2a4a #ffffff #e8f6ff #b8e2f8 #7cc4ec #1f6fb2 #134a80 #ff9f43 #c96a1f #8a94a6 #5c6578 #ff7aa2 #e03e3e #ffd43b #51cf66 #f5e6d3

- `#1b2a4a` — обводка и тёмный текст.
- `#e8f6ff #b8e2f8 #7cc4ec` — лёд (верх, тень, трещины/кромка).
- `#1f6fb2 #134a80` — вода.
- Остальное — коты, рыба, интерфейс, награды.

## Линии и объём
- Обводка: 6 px при размере ассета 256, цвет `#1b2a4a`, одна на весь объект (без внутренних контуров у деталей фона).
- Свет: сверху-слева; блик пятном, без градиентов.
- Тени: одна ступень cel-тени на объекте; под котами — плоский овал тени на льду.

## Льдина (главный элемент экрана)
- Одна льдина целиком на экране. Под ней — шестиугольная сетка механики (4 кольца, 61 клетка), но игрок сетку **не видит**: клетки вплотную, без зазоров, общий силуэт одной обводкой.
- Льдина тонкая: боковая стенка низкая, вид чуть сверху (сжатие по вертикали ~0.62).
- По краю — белая кромка снега внутри обводки.
- Трещины рисуются по клеткам (стадии: целая → треснула → сильно треснула → проваливается), видны поверх единой поверхности.
- Коты маленькие относительно льдины: высота кота ≈ 1/7 ширины льдины.
- В игре льдина собирается кодом из текстур клеток (как на доске: `hexfloe`), а не одной картинкой.

## Персонажи
- Пухлые круглые коты, большие головы, короткие лапы, сумо-пояс маваси.
- Ракурс: чуть сверху (в тон наклону льдины) — учесть при генерации ассетов.

## Шрифт
Rubik ExtraBold (OFL, кириллица), файл в `games/ice-cat-sumo/assets/fonts/` при разработке.

## Интерфейс
Пухлые скруглённые кнопки с той же обводкой, плоская заливка, нижняя ступень тени. Панели светлые `#e8f6ff` с обводкой.

## Промпт
Префикс для `prompts.json`:
```
Flat vector sticker illustration for a casual mobile game, thick dark navy outline, flat bright colors, simple cel shading, cute chunky shapes,
```
Окончание: `isolated on plain solid magenta background, centered, no text,` (магента режется `unify.py cut` чище всего).
Модель: FLUX.2 klein 4B, 4 шага, cfg 1, 1024×1024.
