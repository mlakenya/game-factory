# Ассеты: Котосумо на льдине

> Список из концепта ([ice-cat-sumo](../../knowledge/concepts/ice-cat-sumo.md)) и стиля ([STYLE.md](STYLE.md)).

## Коты (12 × 3 позы = 36)
| Кот | Вид | Пояс |
|---|---|---|
| Мурзик (стартовый) | рыжий полосатый, средний | красный |
| Пушинка | маленькая белая пушистая | розовый |
| Батон | очень толстый серый | синий |
| Ледокол | коренастый чёрный со шрамом | жёлтый |
| Липучка | трёхцветная с большими когтями | фиолетовый |
| Пельмень (чемпион Двора) | круглый кремовый | зелёный |
| Уголёк | поджарый тёмно-серый | оранжевый |
| Тигра | мускулистый полосатый | чёрный |
| Сфинкс | лысый розовый, скользит | бирюзовый |
| Бурун | огромный мейн-кун | тёмно-красный |
| Мармелад | рыже-белый | голубой |
| Полярник (редкий, 5 частей из турниров дня) | белоснежный, ледяной хвост | серебряный |

Позы, все с одним seed на кота:
- `battle` — сумо-стойка, вид чуть сверху. Главный спрайт боя, ~105 px (файл 256). Натяг, рывок, удар — сжатие/растяжение и поворот кодом.
- `ring` — мокрый в надувном круге после падения, ~105 px.
- `win` — победная поза, лапы вверх: полка котов, магазин, итог боя, ~240 px (файл 512).

Соперники-боты (18) и чемпионы (6) — те же 12 тел с шапками и надписями-именами; чемпион — с золотым поясом (`icon-belt` поверх) и
увеличенным масштабом. Силуэт закрытого кота на полке — затемнение спрайта кодом.

## Наряды (8)
Шапки: хатимаки, соломенная, ушанка, шапка с помпоном, корона, викинг, бескозырка, венок. ~50 px на коте (файл 128).
Цвет пояса в v1 — часть кота (без перекраски).

| `ice-hex` | целая / `cracked` / `broken` / `sinking` | клетка ~41 px | текстура 128, льдина собирается кодом (бесшовно, одна обводка) |
| `ice-hole` | прорубь (Пруд) | клетка | 128 |

| `seal` | тюлень толкает льдину (Река) | ~120 px | 256 |
| `iceberg` | айсберг (Северный полюс) | ~140 px | 256 |
| `sun` | тающее солнце (Море) | ~100 px | 256 |
| `wave` | волны (Море) | ~120 px | 256 |
Ветер (Озеро) — частицы и полосы кодом (эффект).

## Фоны (7)
Вода сверху с берегами по краям, центр пустой под льдину; 768×1344, на ПК края дотягиваются кодом.
`bg-yard` (Двор), `bg-pond` (Пруд), `bg-lake` (Озеро), `bg-river` (Река), `bg-sea` (Море), `bg-pole` (Северный полюс), `bg-map` — карта лиги на главном экране.

## Интерфейс
- Кнопки: оранжевая (главное действие), синяя, зелёная (rewarded), серая (недоступно) — 1024×512 → файл 512×256.
- Панель (окна итогов, магазина, паузы), лента-заголовок.
- Иконки (22), ~48 px (файл 128): монета, рыбка-очки лиги, кубок, золотой пояс, замок, звезда, календарь серии, часть кота,
  видео (rewarded), настройки, звук вкл/выкл, пауза, играть, домой, магазин, прокачка: рывок / когти / шубка, галочка, крестик, стрелка.
- Рука-подсказка для первого боя.
- Шрифт Rubik ExtraBold (OFL).

## Эффекты
`fx-splash` (всплеск при падении), `fx-impact` (звезда удара). Трещины, следы на льду, брызги, снег, ветер, конфетти — частицы кодом.

## Что покрыто
Экраны концепта: первый бой, главный (карта + полка котов), бой, итог боя, итог турнира, магазин котов и нарядов, прокачка, ежедневный турнир, пауза.
Крючки: монеты, рыбка-очки, кубок, пояс, испытания (звезда/галочка), календарь серии, части редкого кота, rewarded-кнопки.
Звук — отдельно, на этапе разработки (бесплатные CC0-паки).
