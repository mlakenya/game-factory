# knowledge/

База знаний фабрики. Правила и инструкции живут в скиллах (`.claude/skills/`), а здесь — данные и история.

| Папка/файл | Что | Кто пишет |
|---|---|---|
| `ideas.md` | Реестр идей: номер, статус (идея → концепт → одобрен → в разработке → выпущена) | скан добавляет, статусы — по решению человека |
| `market/daily/YYYY-MM-DD.md` | Ежедневный скан трендов | расписание, скилл `market-scan` |
| `market/weekly/YYYY-Www.md` | Недельная сводка (по понедельникам) | расписание, скилл `market-scan` |
| `market/watchlist.md` | Игры и жанры, за которыми следим | Claude + человек |
| `concepts/<id>.md` | Концепты по выбранным идеям | скилл `concept`, решает человек |
| `postmortems/<id>.md` | Разбор игры через 3 недели | скилл `postmortem` |
| `moderation-log.md` | Все отказы модерации и что исправили | после каждого отказа |
| `templates/` | Шаблоны документов (скилл, концепт, постмортем) | — |
