# Реестр идей

Единственное место, где записан этап каждой идеи. Скан трендов добавляет строки, человек выбирает,
Claude ведёт статусы. Проверка формата: `npm run ideas -- --check` (входит в `npm run check` и CI).
Список по статусам: `npm run ideas`.

## Этапы
| Статус | Что значит | Кто ставит |
|---|---|---|
| идея | Найдена в скане, концепта нет | скан трендов (скилл `market-scan`) |
| концепт | Человек выбрал идею, концепт написан в `knowledge/concepts/<id>.md`, ждёт решения | Claude по просьбе человека (скилл `concept`) |
| одобрен | Человек сказал «делаем» по концепту: механики утверждены | Claude, только по словам человека |
| стиль одобрен | Человек выбрал доску стиля, есть `art/<id>/STYLE.md` | Claude, только по словам человека (скилл `art-style`) |
| ассеты одобрены | Человек принял витрину, есть `art/<id>/assets/` и `CREDITS.md` | Claude, только по словам человека (скилл `assets`) |
| в разработке | Есть `games/<id>/` и ветка `game/<id>` | `npm run new-game` сам |
| выпущена | Игра опубликована в каталоге | Claude после слов человека |
| отклонена | Не делаем (причина в «Заметке») | Claude по словам человека |
| отложена | Не сейчас, вернуться позже (когда — в «Заметке») | Claude по словам человека |

Правила:
- Номер выдаётся один раз и не переиспользуется: 1, 2, 3… Следующий свободный: `npm run ideas -- next`.
  Чтобы попросить концепт, достаточно сказать «концепт для идеи 3» или «концепт для первой и второй».
- Колонка «Концепт» — id будущей игры (латиница, дефис) и ссылка на файл концепта. Пусто, пока статус «идея».
- Концепты не пишутся без выбора человека. Разработка не начинается без статуса «ассеты одобрены».
- Строки не удаляются: отказ — это статус «отклонена», чтобы скан не предлагал идею заново.
