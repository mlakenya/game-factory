# engine/

Общий код всех игр. Игры импортируют его через алиас `@engine/...`.

| Модуль | Что делает |
|---|---|
| `platform/` | Абстракция площадки: Yandex SDK v2, Playgama Bridge и заглушка для разработки/тестов. Адаптер выбирает цель сборки. Игры не трогают SDK напрямую |
| `i18n/` | Локализация, RU обязателен, EN — запасной |
| `save/` | Облачные сохранения через платформу, с дебаунсом |
| `ads/` | Реклама: межстраничная только в паузах, rewarded только по кнопке |
| `audio/` | Общий mute: настройка игрока + системные паузы (реклама, скрытая вкладка) |
| `ui/` | Кнопки, блокировка скролла/выделения/контекстного меню |

Правило: исправление в движке должно проходить `npm run check` для **всех** игр.
