# Промпт для ежедневного расписания: скан трендов

Этот текст вставляется в расписание (scheduled task) Claude. Каждый запуск — новая сессия с репозиторием
mlakenya/game-factory.

---

Ты работаешь в репозитории game-factory (фабрика веб-игр для Яндекс Игр и Playgama).
Сделай ежедневный скан рынка по скиллу `market-scan` (`.claude/skills/market-scan/SKILL.md`):

Этот файл главнее текста расписания: если они расходятся (например, какие файлы коммитить или формат итога), следуй этому файлу.

1. `git checkout main && git pull`.
2. Прочитай скилл market-scan, `knowledge/market/watchlist.md` и последние 3 файла из `knowledge/market/daily/`,
   чтобы не повторять уже найденное.
3. Собери скан за сегодня (дата по Москве) в `knowledge/market/daily/YYYY-MM-DD.md` строго по формату из скилла.
   Источники — из скилла: Яндекс Игры, Playgama и CrazyGames, дальше остальные.
   Используй WebSearch и WebFetch, каждый факт со ссылкой, без выдуманных цифр.
   Прочитай также `knowledge/ideas.md`: новые идеи получают следующие номера и строки со статусом «идея» по правилам
   из скилла, уже известные не дублируются. Концепты не писать и статусы не менять.
4. Если сегодня понедельник — дополнительно собери недельную сводку `knowledge/market/weekly/YYYY-Www.md`.
5. Обнови `knowledge/market/watchlist.md`, если нужно.
6. `npm ci` (если нет `node_modules`) и `npm run ideas -- --check`.
   Закоммить только файлы в `knowledge/market/`, `knowledge/ideas.md` (и, если нашлось изменение правил, `.claude/skills/yandex-moderation/SKILL.md`)
   с сообщением `market: scan YYYY-MM-DD` и запушь в `main`. Ничего другого в репозитории не меняй.
   Если пуш в main отклонён — запушь в ветку `market/YYYY-MM-DD` и открой PR.
7. В конце ответь по-русски, коротко:
   - главное за день, 2–3 строки, ссылка на файл скана на GitHub;
   - новые идеи списком: `N. название и поворот одной строкой (сложность, оценка)`, где N — номер из реестра; если новых нет — так и написать;
   - идеи из реестра, которые сегодня получили новый сигнал (если есть);
   - последней строкой: «Чтобы получить концепт, напишите, например: концепт для идеи N».
