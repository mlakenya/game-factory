# Наряди ёлку (`dress-the-tree`)

Новогодняя сортировка тройками с балансом всей ёлки. Концепт и решения — в `CONCEPT.md`.

- `src/logic/` — правила без Phaser: доска и баланс (`board.ts`), генератор уровней по seed (`generator.ts`),
  решатель (`solver.ts`), звёзды/реклама/отсчёт (`progress.ts`). Тесты: `tests/unit/dress-the-tree.*.test.ts`.
- `content/levels.ts` — 30 уровней: ряды, игрушки, предел наклона, скрытые слои, заснеженные ветки, seed.
  Каждый seed проверяется решателем; если тест уровня упал после правки — подобрать другой seed.
- `content/toys.ts` — 10 видов игрушек; форма = вес (шар 1, шишка 2, колокол 3).
- `src/scenes/` — меню, карта уровней, уровень, оверлей (пауза/победа/проигрыш).
- Графика рисуется кодом (`src/art.ts`), звук синтезируется (`src/sfx.ts`) — файлов ассетов нет.

Для e2e в режиме `?mock` есть `window.__dtt` (состояние уровня, координаты крючков и кнопок).
