# Шаблон `blank`

Минимальный каркас игры: меню → раунд → экран результата. Внутри уже правильно подключены
SDK-жизненный цикл (ready, gameplay start/stop), реклама в паузах, rewarded по кнопке,
облачные сохранения, RU/EN, mute при рекламе и скрытой вкладке.

Это заглушка, а не жанровый шаблон. Настоящие шаблоны (`merge`, `runner`, `puzzle`…)
появляются скиллом `extract-template` из вышедших игр.

- `game.config.ts` — всё, что отличает игру от шаблона
- `content/` — тексты и данные уровней
- `src/` — сцены
- `public/` — ассеты (копируются в сборку как есть)
